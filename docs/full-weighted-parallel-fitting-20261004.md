## Guards for numerical inputs in memory

The new guarded exporter/reader keep likelihood arithmetic, optimizer settings
and comparison tolerances unchanged. They check all cached source arrays at
cohort boundaries, cohort rows/designs/responses/diagonals across each cohort,
and rows/design/response/operator/diagonal arrays around every native fit or
independent numeric replay. Array values and strides are checked. A detected
change preserves before/after digest inventories and changed NPY arrays before
a successful cohort checkpoint can be written. Closed original source files
retain the recoverable pre-call inputs. This detects corruption; it does not
repair the native cause of the earlier species-factor mutation.
