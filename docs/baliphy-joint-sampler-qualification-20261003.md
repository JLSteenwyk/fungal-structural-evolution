## Native and serialized checks

The runner retains the existing independent legacy output checks: exact
configuration/process/command/artifact identities, all 21 scalar rows,
scores and parameter dispositions, rooted tree/candidate correspondence and
all three separate saved alignments. Legacy logs remain separate conditional
draws; they are not substituted for joint sequence/category frames.

The [joint reader](independent-joint-ancestral-frames-20261003.md) separately
checks all nodes in each joint record, source observations and rooted
candidate clades, then exports four candidates' paired states/categories
onto observed-tip residue anchors. Candidate-only insertions retain state,
category and native column. A role receives successful arrays only after
all three native frames pass. Every NPZ value, shape, dtype and key is checked;
all arrays are bound into full source/artifact closure. Unsuccessful or
invalid roles receive explicit dispositions without successful arrays.

The producer uses the existing FIFO memory-reservation implementation, held
through each native attempt and its output audit. The reader repeats native
checks, validates the complete ledger and compares all role records and
summary fields. It first verifies every producer source binding and cannot
recreate a missing export. Existing malformed exports are never replaced.
Completed stages refuse restart and partial controllers require review;
there is no automatic retry or selection among multiple attempts.
