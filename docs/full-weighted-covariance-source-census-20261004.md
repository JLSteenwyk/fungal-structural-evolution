# Full four-control covariance source census

The original source census is running. This stage connects the independently
closed reuse controls to every original design, response input and setting.
It computes no covariance Gram matrices or working-model fits. The project
still targets approximately 500 fungi and 25 outgroups; all eight biological
aims remain incomplete and GPU prediction remains paused.

## Scope and provenance

The frozen [full plan](../metadata/full_weighted_covariance_source_census_plan_20261004_v1.json)
retains 75,188 logical cases, 4,340 cohorts, 34,110,120 cohort-row occurrences,
130,200 fixed designs, 260,400 response inputs and 622,080 model settings.
Each design has two loading modes, five trees and four controls. The future
numerical stage therefore has **5,208,000 audits** and **24,883,200 setting links**.
These are prospective counts; this source census has computed zero numerical
audits. Every setting's policy, scenario, mask, eligibility/screen, order,
response and original disposition remains in its original source table.

Seven closed parents supply operators, designs, raw model inputs, species
factors, exact uniform certificates, positive-diagonal cones and reuse controls.
The loader freshly hashes the entire parent archives and every file consumed
by this stage. It does not claim fresh replay of unconsumed portions of the
parents' much larger native/artifact graphs. Original group assignments rest
on the closed independent SQL/Fraction control readback; this stage does not
rederive them from case-key tables.

The census reconstructs every raw X and y from all **ten** original Parquet
partitions, checking original raw design and response hashes, ordered input
identities, exactly nonzero active columns, finite values, response ranges and
fit-input IDs. It checks all saved control counts, weights, reciprocal diagonals,
recipes and original cohort identities. SQLite checks every original setting
against its design and response input. The serialized reader reconstructs all
cohort records and source/settings checks. It is a source/census readback using
the same reconstruction recipe, **not independent covariance arithmetic**.

## Basis routing

Only an actual all-one diagonal selects the closed named uniform certificate.
All other positive diagonals use the closed positive-diagonal cone, retaining
residual D separately from target I. The original physical-pair exceptions
remain explicit. Constant diagonals other than one and nearly uniform values
do not authorize deletion. Numerical rank cannot change a basis here.

The census chooses no variance policy, transfers no original uniform audit or
error envelope, and supplies no accepted biological or component-attribution
result. Background-node and background-pair policies retain their distinct
logical labels even though their real exported diagonals are identical.

## Resources and execution

Producer and reader each use two CPU cores, 16 GiB cgroup memory, no swap,
one BLAS thread, 12 GiB address space, 21,600 native CPU seconds and a 512-MiB
per-file limit. The CPU cap is neither an ETA nor an enforced wall-time limit.
The [resource plan](../metadata/full_weighted_covariance_source_census_resources_20261004_v1.json)
budgets 2 GiB output/scratch with at least 128 GiB free disk. The cumulative
streaming bounds are 81,864,288,000 predictor bytes and 16,372,857,600 response
bytes; neither is an in-memory allocation. Expanded species factors use at
most 905,263,520 bytes under the original 301-column design. Source control
arrays account for 3,274,571,520 bytes. Runtime is explicitly uncalibrated.

The [launch inventory](../metadata/full_weighted_covariance_source_census_launches_20261004_v1.json)
records the original producer, queued reader and closure. The existing immutable
launcher retains its October 3 suffix in handle filenames; the new plan and
actual launch UTC are October 4. No scientific job was restarted, no paid
infrastructure provisioned and no unrelated resource settings changed.

Full closure requires complete producer/reader equality, every consumed source
and output digest and two actual original process journals. After source closure,
the next gate is fresh full-scope raw/REML numerical qualification with separate
arithmetic, unchanged review policies, resource estimates and measured timing.
Working-model fits and inferential calibration remain later gates.
