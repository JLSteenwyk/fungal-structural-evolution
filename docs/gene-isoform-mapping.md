# Gene and isoform reconciliation

Run `python scripts/download_gene_annotations.py` to acquire assembly-matched NCBI GFFs for the 519 NCBI-backed taxa in the working manifest. The script verifies publisher MD5, records SHA256 and validates feature rows. It resumes by checksum and prevents concurrent writers. Missing or invalid annotations are recorded as errors, never silently interpreted as absence of genes. The seven external taxa require annotation reconciliation from their published bundles separately.

Run `python scripts/map_proteins_to_genes.py` to process the completed annotation downloads. This snapshots current progress while acquisition continues. Exact, versioned protein accessions are followed through GFF Parent links to local gene features. Repeated rows of a multipart CDS remain one feature; multi-parent links are retained. Protein mappings to multiple genes and proteins without a resolved gene remain explicit. Gene IDs are scoped to a taxon and an exact annotation checksum, not assumed stable across annotation versions. These conventions follow [NCBI's GFF documentation](https://www.ncbi.nlm.nih.gov/datasets/docs/v2/reference-docs/file-formats/annotation-files/about-ncbi-gff3/).

Outputs are per-taxon protein-to-gene tables under `results/gene_mapping/` and a versioned summary `metadata/gene_mapping_snapshot.json`. The summary reports genes with multiple protein products; this is not a count of duplications or alternative splice events. No representative isoform is selected yet. Protein sequences remain intact for structural reuse, and the existing raw-proteome BUSCO results retain their original meaning.

Before orthogroup inference, select one representative per confidently resolved gene using a documented policy, retaining all isoforms and selection reasons. Investigate partial CDSs, unmapped accessions and multi-locus proteins. Longest-protein selection can be used as an explicit baseline, but is not proof of the biologically canonical isoform. Reassess apparent BUSCO duplication attributable to isoforms. Never collapse separate loci merely because their sequences are identical.
