# Admission from completed timing to full weighted fitting

The fitting launch must use the same immutable model configuration that
generated the full timing census. Changing that configuration to add scheduling
fields would change its binding map, fit contract and candidate identities.
Operational resources and commands therefore live in a separate request and,
after prerequisites pass, separate admission/resource/operation records.
The measured model plan, source arrays, optimizer settings and scope stay bound.

## Complete source and accounting gate

`full_weighted_fit_admission.closed_timing` requires closed original numerical
and timing stages before loading source arrays. It verifies the original
timing producer/reader/compact completion/full archive, all consumed artifacts,
both original-journal closure counts, source bindings and the measured fit
contract. The reader must have replayed every numeric group and must claim
neither independent hardware duration reproduction nor scientific acceptance.

Admission reconstructs every cohort, candidate identity, source disposition,
maximum-tuple representative, eligible multiplicity, timing export and planning
sum. Every review-array reference is checked against original input bytes.
The completed reader marker, exact artifact set and complete original
candidate count must agree. This repeats full accounting, rather than repeating
the already closed numeric timing probes. It is not a new numeric or biological
qualification. A small synthetic source can pass the general accounting gate
but cannot satisfy the separate production contract.

The production contract retains all 75,188 cases, 4,340 cohorts, 130,200 designs,
260,400 response inputs and 622,080 settings: 20,832,000 potential candidates
and 49,766,400 original-setting links. It retains all controls, loading modes,
trees and methods. Existing primary/independent gradient tolerance 1e-6,
independent batch 32, variance cap 1e6 and explicit search/curvature/replay
settings remain unchanged. No review group is dropped to obtain an admission.

## Conditional capacity and unlaunched operations

Actual completed timing costs inform separate producer and reader CPU
allocations. Each conditional measured cost receives a fourfold capacity
allowance plus 604,800 CPU seconds for uncalibrated source/export/review work.
This is a capacity decision, **not** an expected runtime, mathematical bound,
convergence guarantee or finish ETA. Review groups remain explicit unmeasured
coverage. Source loading and export costs cannot be inferred from point times.

Proposed fitting workers retain two CPUs, 32 GiB, no swap, one BLAS thread,
24-GiB native address space, 2-GiB per-file limits and the existing 3-TiB output/
scratch allowance with 3,172-GiB free-disk threshold. Preparation checks actual
available memory and disk before producing an operational configuration.
It does not install these resources or submit a worker.

The [execution request](../metadata/full_weighted_fit_execution_request_20261004_v1.json)
is currently pending both original closures. The
[actual preflight](../metadata/full_weighted_fit_execution_preflight_20261004_v1.json)
verified the two original closure handles live and produced no fitting output,
operational configuration, fit-resource file or worker. A controller enforcing
actual cgroup/BLAS/native caps and operational pins, followed by complete real
fit/readback/two-journal closure, remains to implement. The request is not a
queued fitting job. GPU prediction stays paused and there is no new charge.

## Software evidence

Three complete copied timing-export grids passed admission over all 72,000
candidate identities, including 320 qualified parent timing groups and all
original exclusions/reviews. Observed hardware timings and numeric results
were inherited from the previously closed software checks. Closure/journal
fixtures here are synthetic. Tests touch only new copied fixture roots;
immutable measured plans and published parent outputs are never modified.

Forty-five rehashed closure/accounting alterations and thirteen production
scope/tolerance relaxations were rejected. Corrupted fixture bytes were restored
and positive full-grid admission reverified. The actual missing prerequisites
were rejected without creating a fitting root. No native model, new numeric
timing probe, biological pilot or scientific effect was fitted by these tests.

The actual original tool wait exited zero. Exact wrapper PID/create/command,
two original wrapper messages and invocation start/completion were verified,
with 429 declared transport/source/generated bindings checked. Native software
CPU use was 53.54 seconds and child peak RSS 172,974,080 bytes; these are not
full-data runtime or memory measurements.
