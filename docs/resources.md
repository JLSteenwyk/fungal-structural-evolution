# Gene annotation acquisition

The working manifest contains 519 NCBI proteomes with matching assembly-specific GFF URLs; seven taxa use published external bundles. Read-only HEAD checks of the first three NCBI GFFs returned 200 with compressed sizes 0.91–1.65 MB. A provisional 1–5 GB storage allowance covers the full NCBI annotation batch, with larger animal annotations expected. Two download workers use the existing host, no GPU or paid services. Runtime is measured during acquisition; transfers may take tens of minutes or longer with retries. Download receipts record actual sizes and publisher checksums. This stage enables gene/isoform mapping and does not itself resolve annotation quality.

Profile alignment comparison uses the already downloaded 125 BUSCO HMMs and complete marker panel, with four CPU processes and no new network, GPU or paid infrastructure. Storage allowance is 1 GB for Stockholm alignments, profile-column FASTAs and audits. Most profiles finish in minutes; long proteins can dominate the remaining runtime. Combined with the existing eight-thread MAFFT batch and single-process gene mapping, the main alignment/preparation stages use approximately 13 CPU threads, well within the inspected host capacity. Per-command logs and checksums support measured follow-up estimates.

The initial full-matrix IQ-TREE guide uses 526 taxa and 49,027 amino-acid sites, 16 CPU threads and a 32 GB memory limit on the existing host. Planning allowance is 1–24 hours for this guide search (16–384 core-hours), to be replaced by observed runtime and IQ-TREE's memory estimate. Reserve 1 GB for matrix, checkpoints and guide outputs. This guide omits bootstrap replicates and is not the final supported species tree; richer models and support analyses require separate resource estimates. There are no GPU or paid-infrastructure costs for this launch.

The frozen OrthoFinder reference core contains 64 taxa and 597,213 proteins; the remaining 462 taxa contain 5,218,634 proteins. Core inference will use 32 DIAMOND search threads and eight analysis workers, FAMSA alignments and FastTree gene trees. Planning allowance is 2–48 hours and up to 200 GB disk for the core, with actual runtime/memory measured from logs before sizing full assignment. Memory is not hard-capped by this wrapper; the refreshed host check showed about 948 GB available RAM and 12 TB free storage. The concurrent guide and MAFFT jobs use 24 additional CPU threads at their configured maxima. No GPU or paid resources are provisioned. A preliminary 1 TB storage allowance for combined orthology remains subject to measured core output; the full assignment launch needs a refreshed estimate.

Individual marker-tree inference covers all 125 profile-aligned markers (73–2,295 retained columns per marker).
