# Full duplicate/reference residue correspondence — verified October 1, 2026

The complete scheduled correspondence grid finished while interactive command
access was unavailable. The original jobs continued; they were not restarted.
This closes residue mapping and provenance checks, not evolutionary inference.

The immutable work design retains all 283,409 original contexts, 214,461 tied
reference records and 428,922 logical duplicate/reference sides, including
unmodeled, identical-model and parent-excluded records. Of 31,235 ordered
physical model triples, 27,056 have source-ready links. Mapping covers all of
these triples under both full and pLDDT70 masks and all eight AB/AR/BR native
order combinations: **432,896 states**, without selecting favorable orders.

Actual full-input preflight exhausted 602,972 input dispositions from the
primary and additional reference manifests. The required 78,879 models have
78,879 ready full inputs, 74,823 ready pLDDT70 inputs and 4,056 explicitly short
pLDDT70 inputs. Input closure verified 86 bindings and the original journal.
The original-length median is 334 residues and maximum 2,271. The prelaunch
upper bound was 208,929,520 residue-triple occurrences across both definitions;
it was a planning bound rather than an observed mapping result.

Reference measurements now contain all 222,804 directed states for 55,701 pairs:
99,788 new-native, 121,556 old-reference and 1,460 completed-primary states.
All 95,062 newly aligned states underwent numerical and independent geometry
checks; seven RMSD discrepancies and 75 degenerate geometries remain flagged.
The complete union retains 213,791 numerically usable states, 8,880 unavailable
inputs and all 133 numerical exclusions. These are overlapping quality criteria,
not estimates of biological effects. Four exact original journals close the new
measurements; two each close the union and full reference coverage.

Full reference coverage reconstructs all 111,402 pair/mask rows and 668,412
six-screen decisions using both native orders and original full-protein lengths.
At 50 residues/70% coverage, 23,574 full pairs and 15,783 pLDDT70 pairs pass;
15,782 pass both masks. The full contextual projection also passed independent
SQL reconstruction of 6,801,816 context/screen states, 34,009,080 five-policy
decisions and 5,147,064 logical side/screen decisions. Parent exclusions and
original lexical choices remain mandatory; physical availability does not
override eligibility.

For each scheduled triple, the mapper reads actual checkpoint directions,
checks current and original source orders, masked sequences and written-input
hashes, then reconstructs residue pairs on original protein positions. AR/BR
intersection gives the reference-common triples; agreement with the AB relation
defines a separate cycle-consistent subset. The output contains **81,029,452
reference-common** and **73,255,758 cycle-consistent residue occurrences** across
the grid. These totals include order/mask alternatives and are not independent
sites or events. Excluded native maps remain visible, and short or failed cores
cannot be promoted to geometric fits. All six both-order pair-screen flags for
all three edges are retained separately from future shared-core coverage.

An independent reader reconstructs positions with iterators and checks AB
membership with a relation set, rather than importing the producer's mapping
or intersection algorithms. It checked the complete ordered grid, all fields,
source classifications and aggregate counts. Completion binds **321,723
source/artifact hashes and both exact original producer/reader journals**.
Production v2 preserves inherited failed-reference status reasons exactly once,
as well as primary blank numerical fields. The input-preflight-pinned prototype
files remain immutable. Synthetic software fixtures exercised 32 states and
rejected 12 rehashed false exports; they are not a sampling pilot.
